02How it works

Small by design.

Priced before it's built

Every service has its price and build time on the services page. If something needs to grow, you hear about it before the work, not after.

Built on what you already use

WhatsApp, Telegram, Google Sheets, your existing phone line. Systems fit around how your team already works.

Handed over, not locked in

What's built for you is yours. If you ever want someone else to take it over, nothing stands in the way.

03Why hand-built

Written by hand, fast on any phone.

Every site here is plain HTML, CSS and a little JavaScript, with no page builder underneath. It's the same way this site is made.

This page, including its styles and scripts, is gzipped. That's measured when the site is built, not estimated.

Fast on slow connections
Nothing heavy to download before the page appears, so it opens quickly on a mid-range phone on mobile data.
Nothing to patch
No plugins, no admin panel, no weekly security updates. Very little can break.
Outlives the tools
Plain HTML still opens in any browser years from now.
