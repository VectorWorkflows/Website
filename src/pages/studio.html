STStudio

{% rise %}One person, every line.{% endrise %}

Vector Workflows is a one-person studio. The person who scopes your project is the person who builds it, deploys it, and answers when something needs to change. There's no account manager in between.

01How it works

Small by design.

Scoped before it's built

Every project starts with what's included, what isn't, a starting price and a build window. If something needs to grow, you hear about it before the work, not after.

Built on what you already use

WhatsApp, Telegram, Google Sheets, your existing phone line. Systems fit around how your team already works instead of asking them to learn new software.

Handed over, not locked in

You get the source code and run it on your own accounts. If you ever want someone else to take it over, nothing stands in the way.

02Why hand-built

Page builders rent you a website. This kind is yours.

Every site here is written by hand: plain HTML, CSS and a little JavaScript, with no page builder or framework underneath. It's the same way this site is made.

This page, including its styles and scripts, is gzipped. That's measured when the site is built, not estimated.

Fast on slow connections
No builder runtime to download before anything appears. Pages open quickly on a mid-range phone on mobile data.
Nothing to patch
No plugins, no admin panel, no weekly security updates. There's very little that can break.
Outlives the framework
Plain HTML still opens in any browser years from now, long after today's tools have moved on.
No platform fee
A static site can be hosted cheaply or for free, and you're never paying monthly just to keep it online.
