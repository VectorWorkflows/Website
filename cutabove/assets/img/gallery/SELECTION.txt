HOW THIS SELECTION WAS MADE
===========================

Source: 90 files downloaded from @cutabovedubaisalon — 80 stills, 10 reels.

MECHANICAL PASS
  - 10 .mp4 reels set aside (not used; the gallery is stills only for now)
  - 2 exact duplicates removed:
        003_Ctq_vNopaUS_1.jpg == 004_Ctq_vNopaUS_1.jpg
        014_C8_j23mJMt0.jpg   == 015_C8_j23mJMt0.jpg
  - perceptual-hash check for near-duplicates: ZERO found. The carousel
    siblings are genuinely different shots, not repeats.
  - 4 story reposts had their white letterbox bars trimmed off
  - everything resized to 1400px long edge, q80 progressive
    (78 usable stills -> 38 selected, 8.7 MB total, ~230 KB each)

EDITORIAL PASS
  The set skews very heavily toward one look: long wavy blonde balayage on
  young women. Roughly 60 of the 78 are some version of it. Ranking purely on
  sharpness or resolution would have produced a gallery of forty photographs
  that all look like the same appointment.

  So the rule used was: ONE hero per Instagram post, then prune for repetition
  across the whole set, then deliberately protect whatever was rare.

  Protected because there is only one (or two) of them:
    03.jpg  red gel nails        — the only nail photograph in the whole set
    02.jpg  curly cut            — the only two curly clients
    17.jpg  perm, defined curl
    06.jpg  copper red           — the only warm/red colour
    08.jpg  platinum crop        — the only genuinely short cut
    10.jpg  product still life   — the only non-portrait; a texture break
    15.jpg  extensions fitted    — craft/behind-the-scenes
    22.jpg  Great Lengths weft
    13.jpg  occasion styling     — the only event/gown look
    18.jpg  magenta
    24.jpg  lilac panel

  Order is interleaved on purpose so the top of the masonry grid is not eight
  blondes in a row. It is not chronological.

TO CHANGE ANYTHING
  Swap a file: overwrite NN.jpg with any image and it is picked up on reload.
  Add more: continue at 39.jpg, 40.jpg and raise COUNT in assets/js/data.js.
  Remove one: delete the file. The tile removes itself; no renumbering needed.
  Captions and categories: CA.galleryMeta in assets/js/data.js.

  Captions are plain visual descriptions, NOT claims about which treatment was
  performed. Replace them with the salon's own words before anything goes live.
